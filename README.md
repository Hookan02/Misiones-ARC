# ARC Raiders: misiones por mapa

Página interactiva para completar las 137 misiones de ARC Raiders de forma ordenada: una pestaña por mapa, pasos por lugar y requisitos de cada misión. El progreso se guarda en el navegador de cada persona.

## Cómo usarla

Abre la página, elige un mapa, marca cada paso que completes y la misión se marca sola al terminar todos. Con "Solo las que puedo hacer ya" ves únicamente las misiones desbloqueadas.

## Datos

Los datos de las misiones están recopilados a partir de [RaiderBuddy](https://raiderbuddy.com/quests) y de la [wiki de ARC Raiders](https://arcraiders.wiki/wiki/Quests). Los nombres de misiones, lugares y objetos están en inglés, como en el juego. El juego se actualiza y puede haber misiones nuevas que no aparezcan aquí.

Proyecto no oficial, sin relación con Embark Studios.
